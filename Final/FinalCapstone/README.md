# Final JavaScript + TypeScript Capstone: A Production-Grade Platform

[🏠 Course](../../README.md) · [🗺️ Roadmap](../../ROADMAP.md)

⏱️ about 5 weeks · Scoring scheme **B**

## 🎯 Brief

TypeScript frontend → typed API layer → Node/TypeScript backend → domain layer → data layer → database. No React required at first.

## ✅ Requirements

- [ ] Strict TypeScript everywhere
- [ ] Authentication & authorization
- [ ] A complex domain model
- [ ] API with shared contracts
- [ ] Database
- [ ] Async processing (jobs/queues)
- [ ] Runtime validation at every boundary
- [ ] Caching
- [ ] Error architecture (Result types + layers)
- [ ] Logging
- [ ] Unit, integration and E2E tests
- [ ] CI pipeline
- [ ] Architecture documentation

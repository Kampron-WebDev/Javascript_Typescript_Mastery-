# Final Advanced Challenge: Rescue the Codebase

[🏠 Course](../../README.md) · [🗺️ Roadmap](../../ROADMAP.md)

⏱️ about 1 week · Scoring scheme **B**

## 🎯 Brief

You receive an intentionally bad JavaScript codebase. Your assignment: turn it into professional software, and defend every major decision.

## ✅ Requirements

- [ ] 1. Find bugs
- [ ] 2. Identify architectural problems
- [ ] 3. Add TypeScript
- [ ] 4. Improve the domain model
- [ ] 5. Refactor the modules
- [ ] 6. Improve error handling
- [ ] 7. Add tests
- [ ] 8. Improve performance
- [ ] 9. Document the architecture
- [ ] 10. Defend every decision (recorded presentation)

## 📊 Rubric (100 points)

| Area | Points |
|---|---:|
| Functionality: every requirement works, edge cases handled | 30 |
| Code design: clear modules, names, no duplication | 20 |
| Tests: meaningful, green, cover the core logic | 20 |
| Error handling & robustness | 10 |
| Documentation: README + ARCHITECTURE.md | 10 |
| Defence: you can justify every major decision | 10 |
